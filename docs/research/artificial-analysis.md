## 1. Endpoints

Base URL (current, confirmed in OpenAPI spec `servers` + docs): **`https://artificialanalysis.ai/api/v2`**

Auth: **every endpoint requires one header, `x-api-key: YOUR_API_KEY`**. No OAuth, no bearer exchange, no request signing. Keys are scoped to organisations; create/copy one at [API key management](https://artificialanalysis.ai/api-key-management-redirect) (login required; if signed out you are routed through login and back). Treat keys as server-side secrets — never ship in client-side code. Regenerating a key revokes the old value immediately.

Language-model endpoints (from the live OpenAPI 3.1.0 spec at `GET /api/v2/openapi`, `info.version: "2.0"`):

| Method + path | Tier | Purpose |
|---|すすめ---|---|
| `GET /api/v2/language/models/free` | Free, Pro, Commercial (Free-shape body; `tier` field reflects caller) | **The free-tier endpoint.** Headline indices, median performance, input/output/cache pricing, index cost totals. This is the one `rack-rate` would call. |
| `GET /api/v2/language/models` | Pro+ only (Free key → `403`) | Full model list: per-benchmark scores, blended pricing, percentile/quartile performance, context window, params, modalities, licensing. Query params: `prompt_type`, `page`. |

| `GET /api/v2/language/models/{slug}/performance?window=7d\|30d\|90d&interval=daily\|weekly\|monthly` | Commercial only | Performance-over-time series per provider. |
| `GET /api/v2/language/providers`, `.../{slug}` | Commercial only | Provider-level pricing/performance. |

Error semantics (verified from spec `components.responses`): `401` = missing/invalid key (`{"error": "API key is required"}`); `403` = valid key but tier doesn't cover the endpoint; `400` = bad query param (message names the field); `404` = bad slug (`{"error": "Model not found: <slug>"}`); `429` = quota exhausted, with `Retry-After` seconds; `500` = retry with exponential backoff. Every authenticated response (success **and** error) carries `X-AA-Tier`, `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` (unix timestamp of fixed-window end).

## 3. Refresh

- **Cadence:** continuous — "Models, providers, benchmarks, and prices update as we publish them" (`/data-api`). New model evaluations land near-daily (homepage changelog showed entries dated 13/10/7/4/3/2 Sept 2026). No published SLA, webhook, ETag, or `Last-Modified` contract `[UNVERIFIED — headers not observable without a key]`; polling is the only mechanism.
- **Stability/versioning:** wire format is append-only by policy — "fields are deprecated, not renamed" (spec §Data conventions). Score semantics are versioned via `intelligence_index_version` (major.minor). Scores "are best interpreted within the same major version" (spec §Intelligence Index versioning).
- **Staleness detection:** (1) compare stored `intelligence_index_version` against the fresh response's — on bump, **re-fetch everything and never mix versions in one table**; (2) `release_date` + homepage `/changelog` for new-model coverage gaps; (3) track `X-RateLimit-*` headers to confirm live quota state, not a cached fetch. There is no per-model `updated_at` field — row-level freshness is `[UNVERIFIED]`.
- **Practical implication for `rack-rate`:** refetch the ~2 pages on each site build, persist `intelligence_index_version` + fetch timestamp into `data/*.json`, and render the version next to every score. With only ~2 requests per build against a 100 req/day quota, daily rebuilds are sustainable.

## 5. Recommended TS fetch strategy

Target path: **`scripts/fetch-aa.ts`** (fetch + normalize + validate; writes `data/aa-models.json` — local build artifact only, see § License: do not commit redistributed values without a Commercial license).

```ts
// Bun + TypeScript. Key NEVER in client bundle — build-time only.
const BASE = "https://artificialanalysis.ai/api/v2";

export async function fetchAAModels(apiKey: string): Promise<AAResponse> {
  const models: FreeModel[] = [];
  let page = 1, version: number | null = null;
  for (;;) {
    const res = await fetch(`${BASE}/language/models/free?page=${page}`, {
      headers: { "x-api-key": apiKey },
    });
    if (res.status === 429) {
      const wait = Number(res.headers.get("Retry-After") ?? 300) + 5;
      await Bun.sleep(wait * 1000); continue; // fixed 24h window; Retry-After is authoritative
    }
    if (!res.ok) throw new Error(`AA ${res.status}: ${await res.text()}`);
    const body = await res.json();
    if (version === null) version = body.intelligence_index_version;
    else if (body.intelligence_index_version !== version)
      throw new Error("AA index version changed mid-paginate — abort, refetch all");
    models.push(...body.data);
    if (!body.pagination.has_more) return { version, fetchedAt: new Date().toISOString(), models };
    if (++page > body.pagination.total_pages) break;
  }
  throw new Error("AA pagination inconsistent");
}
```

- **Retry/caching:** ~2 requests per full sync — no concurrency needed. Retry `429` on `Retry-After`, `500` with exponential backoff (1s→2s→4s, max 3), fail fast on `401` (bad key) and `403` (wrong endpoint for tier — a Pro route called with a Free key). Cache raw responses to `.cache/aa-models-<version>-p<page>.json` keyed by `intelligence_index_version`; skip network when cache version matches and is <24h old. Never commit the API key; read from `AA_API_KEY` env. Log `X-RateLimit-Remaining` per build so quota burn is visible (100/day Free burns fast if every dev machine fetches).
- **Validation:** zod-schema the envelope (`tier`, numeric `intelligence_index_version`, `pagination`), require `id`/`slug`/`name` per row, assert the 3 free `evaluations.*` keys are `number|null`, assert `pricing.*`/`performance.*` keys are `number|null`, and **persist `intelligence_index_version` + `fetchedAt` in the JSON** — the validator must reject any file missing them.
- **Staleness guard:** if a new fetch reports a different `intelligence_index_version`, discard the old file entirely (never merge v4.x rows with v4.y rows in one table).

## 6. Gotchas / unknowns

1. **Legacy `/api/v2/data/llms/models` path is superseded** — current contract only defines `/api/v2/language/models[/free]`. Whether the old path redirects, 404s, or still serves is `[UNVERIFIED]` (no key to probe). Do not implement against it.
2. **Legacy docs say "1,000 requests per day"** (`/api-reference` free-API section) while the current spec + `/data-api/docs` + `/data-api` all say **Free = 100 / 24h fixed window**. Treat 100 as authoritative (spec is generated from the Zod contract); the 1000 figure is stale. Pro = 500/day; CritPt grader has its own 10/day limit.
3. **Spec examples are stale (show `intelligence_index_version: 4.1`)** while the live index is **v4.3** — examples lag the product. Always read the live `intelligence_index_version` field; never hardcode 4.1.
4. **`intelligence_index_version` hides patch versions** (major.minor only) — patch-level grader/dataset upgrades can move scores invisibly. Scores can shift without any version signal you can see.
5. **Free endpoint has no `prompt_type` param** (Pro list/detail default to `long` = 10k input tokens; legacy free docs mention `medium` = 1k). Which workload the free medians are measured under is `[UNVERIFIED]` — do not label them "1k-token latency" without confirmation.
6. **`page_size` is not settable** — don't send it; whether the server ignores or `400`s it is `[UNVERIFIED]`.
7. **Reasoning-effort variants are separate records** (`gpt-oss-20B (high)` vs other efforts) — dedupe/aggregate deliberately; don't assume one row per model family.
8. **`artificial_analysis_intelligence_index_cost` IS free-tier** (totals only) — the brief's suspicion that cost might be paid-only is resolved: free includes `total_cost` + `cost_per_task.total_cost`; only the input/reasoning/answer splits are Pro.
9. **Nulls are routine** (unmeasured models, missing cache pricing) — every numeric leaf must be `number | null`, never defaulted to 0.
10. **Rate-limit scope is shared** per user-in-organisation — all keys in the scope share one 100/day bucket; CI + dev machines can starve each other. Fixed (not rolling) 24h window anchored at first request after expiry.
11. **401 bodies are unauthenticated** (no `X-AA-Tier`); `403` on `/language/models` with a Free key is expected behaviour, not an error to retry.
12. **Biggest unknown: redistribution negotiability.** The public terms unambiguously forbid our use case on Free/Pro, but whether AA grants Commercial redistribution to a small open-source static site (and at what price/terms) is `[UNVERIFIED]` — only a reply from the sales/contact channel answers it. Second unknown: whether legacy `/data/llms/models` still works with existing keys (`[UNVERIFIED]`).
