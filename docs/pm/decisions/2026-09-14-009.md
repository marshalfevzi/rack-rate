# Link construction is split into a route builder, a file builder and an absolutiser

## Context

From the Stage 3.3 + 3.3b session's owner decisions:

- Links are split into a route builder and a file builder, with a separate absolutiser, because the trailing slash and the base belong to path construction; `absoluteUrl` doing prefix detection was rejected as a whole-function heuristic.
- The footer's credits are static text in the layout. The verbatim Awesome Coding Plan attribution stays owned by `/sources` rendered from `data/sources.json` in 3.11, so the validated string is not duplicated — and so 3.3 does not front-run 3.5's data accessor by importing raw JSON.

## Decision

Links are split into a route builder and a file builder, with a separate absolutiser. The footer's credits stay static text in the layout, and the verbatim Awesome Coding Plan attribution stays owned by `/sources` rendered from `data/sources.json` in 3.11.

## Consequences

`href()` joins `BASE_URL` and adds the trailing slash; `asset()` adds none; `absoluteUrl` only absolutises. Every internal link goes through the helper. The footer's credits stay static text so the validated attribution string is not duplicated, and so 3.3 does not front-run 3.5's data accessor by importing raw JSON.
