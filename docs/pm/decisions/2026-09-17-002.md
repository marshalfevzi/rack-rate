# The Console Listing is the frozen visual world for the redesign

## Context

The 2026-09-16 design session replaced the incumbent dark card grid with 'Divine Machinery: the Console Listing' — a mainframe console/ISPF panel of fixed-column listing paper, a line-number gutter, a carriage-control state column, printer rules, uppercase mono legends, 0 px radius, one amber signal and a six-step IBM Plex type scale. `DESIGN.md` owns the durable system and the token values, `docs/design/surfaces.md` owns per-route layout, and the `/` surface brief owns the direction contract; the committed captures under `.impeccable/review/incumbent/` are the anti-reference. Milestone M5 is the sequencing that builds it.

## Decision

No M5 task re-opens the world. M5 changes presentation, composition and chart grammar only — no data, no arithmetic, no route identity, no schema — and `DESIGN.md` remains the only owner of token values. M6 adds behaviour, not appearance: it may not add a token, a hue, a radius or a second duration, and a new visual need is either an M5 follow-up or a `DESIGN.md` change, never a page-local override. The one contradiction between the two design documents is resolved in favour of `docs/design/surfaces.md` by UI-504: the cursor readout docks as the fixed 28 px line at the viewport bottom (≥768 px) and inline under the band below that; UI-515 corrects the `DESIGN.md` sentence.

## Consequences

`apps/site/src/lib/prefs.ts` is not created in M5 — it is APP-601 — so every M5 state mark is URL or session state and no surface may imply a saved preference. Five chart builders that were only ever verified by rendering gain unit tests in UI-509. Incumbent visual residue is removed by UI-514, and the design record is re-derived from the built world by UI-515.
