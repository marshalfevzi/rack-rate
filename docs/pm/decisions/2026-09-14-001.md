# Initialization stack: Bun workspace, committed data snapshot, Astro site, Pages-first hosting

## Context

The bootstrap session fixed the stack before Stage 1 was executed by an agent, and recorded it under `**Decisions taken at initialization**` because later stages depend on it. The clean cutover away from the Python pipeline in Stage 1.5 was **planned**, not yet executed, so `scripts/*.py`, `site/` and `vercel.json` were still present in the tree at that point; the `### 2026-09-14 — Stage 1 executed (initialization complete)` session then landed it.

## Decision

The initialization stack, quoted from the recorded decisions:

- Bun workspace with three packages;
- committed normalized data snapshot that the site builds from;
- Astro + Tailwind v4 + tree-shaken ECharts;
- GitHub Pages project page now with a two-line switch to `rackrate.dev`;
- Artificial Analysis **off by default** because no redistribution right exists.

## Consequences

The site builds from committed JSON and never performs a client-side data request. The Pages→domain switch stays a two-line config change. Artificial Analysis is excluded from data, composites and the site unless it is enabled explicitly — see `DEC-2026-09-17-001` (`docs/pm/decisions/2026-09-17-001.md`).
