## Scope

**Choose and lock the replacement visual world.** The incumbent world — the Console Listing that `DESIGN.md` locks — is rejected as the direction. This task produces its replacement and nothing else: no route is edited, no component is rewritten, and `apps/site/src/styles/global.css` is not touched.

**Files:** `DESIGN.md`; `.impeccable/design.json`; `docs/design/surfaces.md` (only where it restates token values); one throwaway specimen route under `apps/site/src/pages/` that is deleted before this task finishes.

**Work:** derive three candidate worlds and render each as a specimen — the same content, the same eleven-route inventory, the same evidence contract, three different visual systems — then have the owner choose one. The chosen world is written into `DESIGN.md` as the locked contract with every token value contrast-audited in both schemes, and the two rejected directions are recorded as anti-references with the reason each lost.

Each candidate must be a world and not a restyle. It names its ground, its type scale and faces, its rule and elevation language, its colour policy (how many hues exist and what each means), its density, its shape language, its motion policy, and its data-graphics grammar. Each renders, from a built preview, the same three proofs: a dense listing table, a chart plate with its table twin, and a page carrying prose plus a control row.

**The failure this task exists to prevent:** the incumbent world was locked before the owner ever saw it rendered on a real route, so a whole stage was built on a direction nobody had chosen. Here the direction is chosen from rendered specimens first.

## Done when

- `DESIGN.md` describes the chosen world, and the Console Listing is recorded as a rejected direction rather than amended.
- Three candidate worlds were rendered and inspected at 1440px, 768px and 360px, in both schemes, and the owner chose one between them.
- Every text pair in the chosen world clears 4.5:1 against its binding ground in both schemes, with the measured ratios written into `DESIGN.md`.
- The chosen world states its colour policy explicitly, so a later task cannot add a hue by accident.
- The specimen route is deleted; `bun run build` completes without it.

## Acceptance criteria

- [ ] Every clause of **Done when** holds, verified from a built preview (`bun run build` then `bun run preview`), never `astro dev`.
- [ ] `DESIGN.md` is the sole owner of every token value the specimen rendered.
- [ ] No file outside the list above changed.
