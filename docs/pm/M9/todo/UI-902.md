## Scope

**Rebuild the design system from the chosen world.** Every visual value the site ships is re-derived from `UI-901`'s locked contract rather than patched. The Console Listing tokens, primitives and chart grammar are replaced, and the code that obsoletes is deleted rather than left as an alias.

**Files:** `apps/site/src/styles/global.css`; `apps/site/src/components/` (the primitive set, including the shell components `Base.astro`/`Page.astro` compose); `apps/site/src/layouts/Base.astro`; `apps/site/src/layouts/Page.astro`; `apps/site/src/lib/charts/theme.ts` and `apps/site/src/lib/charts/frame.ts`; `ARCHITECTURE.md`'s design-token section.

**Work:** land the token set the world names — grounds, rules, text levels, colour policy, the type scale with its pixel line-heights and face roles, the spacing rhythm, the radius and elevation language, the focus treatment, the browser-surface theming, and one motion duration with one easing plus a `prefers-reduced-motion` branch. Then rebuild the primitive layer against it: the shell (whatever replaces the status band, the lane rail, the drawer and the footer index), the row and listing primitives, the control primitives, the empty and error grammar, and the chart grammar in `theme.ts`/`frame.ts`.

**The chart grammar is load-bearing here.** `apps/site/src/lib/charts/theme.ts` is why no chart draws today: it reads colour token names that `UI-501` deleted, and `resolvedToken` throws on an empty value, so every mount fails before the renderer is reached. The rebuilt module reads only names that exist in the emitted `@theme` block, and it fails loudly at build time rather than silently at mount if the world adds or renames a token.

**Delete, do not alias.** A retired token, utility class or component leaves the tree when its replacement lands. No shim, no deprecated re-export and no page-local override survives this task.

## Done when

- The emitted stylesheet's token set is exactly the chosen world's token set: no retired name remains and no unlisted name appears.
- Every primitive in the component set carries the full state set the world prescribes, with rule, glyph, label or inversion beside any tonal change.
- All six chart builders draw from a built preview with the rebuilt grammar, and no chart mount fails.
- `theme.ts` names no token that is absent from the emitted `@theme` block, and a missing name fails the build rather than the mount.
- `ARCHITECTURE.md`'s design-token section describes the shipped system, with no sentence left over from the Console Listing.

## Acceptance criteria

- [ ] Every clause of **Done when** holds, verified from a built preview (`bun run build` then `bun run preview`), never `astro dev`.
- [ ] Both schemes render identical geometry, with values the only difference.
- [ ] No route under `apps/site/src/pages/` was edited by this task; the routes are rebuilt by `APP-904`, `UI-903` and the route tasks.
