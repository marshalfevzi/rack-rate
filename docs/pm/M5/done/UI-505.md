## Session

Put the whole component layer on the Console Listing grammar. `apps/site/src/lib/provenance.ts` now owns the console state vocabulary — `PrimitiveState`, the seven-mark `StateMarkKind` alphabet, `STATE_MARKS`, `STATE_MARK_TERMS` and the five `LISTING_COPY` strings from `docs/design/surfaces.md`'s Copy rules — so no component re-types a state string; `apps/site/src/lib/readout.ts` lost its one inlined copy of `No committed rows for this view.` to that constant. The six provenance components were rewritten (`Badge` dropped its `tone` prop and the api/adjusted hues; cost bases are told apart by words and stroke grammar only) and eight primitives landed: `SectionHead`, `Plate`, `Chip`, `ControlRow`, `StateCell`, `Gutter`, `SetAside`, `EmptyState`. Every primitive renders its prescribed state set as `data-state` plus a rule, glyph, label or inversion; `StateCell` carries exactly one carriage-control glyph with its `sr-only` term label and the mark's description in `title`; `SetAside` keeps excluded rows visible with their reason and prints `No excluded rows in this view.` (the constant) rather than disappearing at zero rows; `CiBar` is a 1px interval rule whose stroke weight follows confidence (measured 2px, high 1.5px, medium 1px, low 0.75px).

Resolved during intake: the data-row height contract lives on `Gutter` and `StateCell` (44px below 768px, 36px at ≥768px) because the package's frozen file list has no `Row` primitive, so a reading row measures 36/44 with no page-local height and `StateCell` keeps the height when the gutter drops below 480px; the row's deep-link `id` stays the caller's. No dependency, no route, no page file and no `global.css` edit: all eleven routes still build untouched, and `apps/site/src/lib/prefs.ts` still does not exist. `apps/site/src/lib/readout.ts` and `apps/site/src/pages/method.astro` keep their existing duplicate strings except the readout constant; `method.astro`'s copy migrates with UI-513.

Evidence came from a built preview (`bun run build`, then a `bun run preview` served as a `hub` process), never `astro dev`: a temporary `__primitives` page rendered all fourteen components, measured 36px rows at 1440/768 and 44px at 390, a 20px state cell that never dropped, a 40px gutter at ≥768 and 28px at 600 with `display: none` at 390, `border-radius: 0px`/`box-shadow: none`/`background-image: none`/`filter: none` across 75 state-marked nodes, a 2px `rgb(255,176,32)` focus ring at 2px offset, one blank glyph plus an `sr-only` `Live` label in the default state cell, and `scrollWidth === clientWidth` at 1440/768/390 with a light-scheme capture keeping identical geometry and a greyscale capture losing nothing contractual. The fixture was then deleted and the final build produced 53 pages and the 1200×630 card, with no route beyond the frozen eleven. Measurements are recorded in `ARCHITECTURE.md`'s `### Stage 5 record — listing primitives and provenance components (task UI-505)`, which also names the eight primitive contracts in the `## Provenance components` table.
