## Scope

**Self-hosted IBM Plex, its licence, and the two generated assets.**
**Files:** the five latin-subset woff2 faces
`apps/site/src/assets/fonts/ibm-plex-sans-latin-{400,500,600}-normal.woff2` and
`apps/site/src/assets/fonts/ibm-plex-mono-latin-{400,500}-normal.woff2`, the two
Satori faces `apps/site/src/assets/fonts/ibm-plex-sans-latin-{400,600}-normal.woff`,
and `apps/site/src/assets/fonts/LICENSE.txt`; `apps/site/astro.config.mjs` (the
`fonts` block); `apps/site/src/layouts/Base.astro` (`<Font />` in the head);
`apps/site/src/styles/global.css` (`--font-sans` / `--font-mono`);
`apps/site/scripts/og.ts`; `apps/site/public/favicon.svg`; delete
`apps/site/assets/fonts/**` only once nothing references it.
**Work:** acquire the seven faces once from the `@fontsource` jsDelivr file paths
(`@fontsource/ibm-plex-sans@5.3.0` and the matching `ibm-plex-mono`), commit them
with the IBM Plex OFL 1.1 text, and record each file's source URL, byte length and
sha256 in `ARCHITECTURE.md` so the committed bytes stay verifiable. Register both
families in the Astro Fonts API — `fontProviders.local()` over the committed woff2,
`formats: ["woff2"]`, `cssVariable: "--font-plex-sans"` and `"--font-plex-mono"`,
real fallbacks — and include `<Font />` for each family in the `Base.astro` head, so
Astro generates the `@font-face` rules, the preload links and the metric-matched
fallbacks instead of hand-written CSS. Point `--font-sans` and `--font-mono` in the
`@theme` block at the Astro variables; keep prose in Sans and figures in Mono. No
remote font provider: the build keeps working offline (invariant 9). Move `og.ts`
off Lato onto Plex Sans 400 and 600, read from the two committed `.woff` faces
because Satori reads TTF, OTF and WOFF but never WOFF2, and map the card's
`fontWeight: 700` onto the frozen 600 step; its palette reader keeps following
`@theme`. Update the two media-scoped `theme-color` values to the frozen canvas
values. The favicon keeps its 32×32 SVG geometry and is judged at the 16px a
browser tab actually renders, not at an authored size: if the 1.5px rule weights
close up at that size, adjust the rule weights only — the geometry, the gutter and
the single amber signal stay as they are.
**Done when** the browser loads only the woff2 emitted by the Astro font pipeline
(hashed under `_astro/fonts/`) with zero remote font requests and no build step
reaches the network, every committed face's sha256 and byte length matches its
recorded value, computed styles report Plex Sans for prose and Plex Mono for data,
the favicon reads at 16px, `dist/og.png` is 1200×630 in the console palette, and no
Lato family or path remains anywhere in the tree.
