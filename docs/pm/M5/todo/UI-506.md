**Work:** recompose the entry as the split console: the left selection column is
plan → models → tasks per month, pre-filled with a real committed plan and its
measured-against model, and the right column is the readout listing
(`Plan · Model priced · Effective monthly cost · Break-even tasks/month`, with
the last two numeric and right-aligned, the line-number gutter, the 2px head
rule and a foot line carrying the route count and the API-list multiple), with
the effective-cost head stating `API list` in words; keep the ported
calculator's arithmetic and its missing-route reasons exactly; serialize every
control to the URL (`plan`, `models`, `tasks`) and restore from it; replace the

readable without hover. The surface brief's first viewport is band + rail +
split console, so **no authored figure opens `/`** — the headline is the

placeholder, changing plan, models or task count writes the URL and a reload
reconstructs the state, the five former insight statements are rows rather than
paragraphs, and the browser makes no `.json` or API request.

### Stage 5 record — `/` the split console (task UI-506)

Relocated verbatim from `ARCHITECTURE.md` on 2026-09-17; a reference document holds current truth only, so this per-task record lives with the task instead.

UI-506 turns `apps/site/src/pages/index.astro` into the Stage 5 split console.
The server renders the committed plan/model route table, headline index, headline
figures, independent gap set-asides, and the readout prefill. The inline
`console-data` payload is the only client input; the browser owns plan/model/task
selection, canonical `history.replaceState` URL serialization, row cloning, and
the effective-cost arithmetic without a fetch or a client-side data request.
`apps/site/src/lib/readout.ts` no longer carries the unreachable `/` switch arm.

The console keeps the listing contracts from UI-505: native labelled controls,
`StateCell`, `Gutter`, `SetAside`, `EmptyState`, `SourceLink`, `CostBasisChip`,
readout attributes on every row, identity links, and keyboard-visible row focus.
The table header is sticky beneath the status band on desktop; phone layouts
collapse the header into labelled stacked cells, remove the gutter, and preserve
the state mark. No-query defaults resolve to `claude-pro`, `claude-opus-4.8`,
and 300 tasks; invalid URL values fall back to committed defaults, while an
unknown model selection renders the filtered empty state.

The built preview at `http://localhost:4321/rack-rate/` was exercised at
1440 × 900 and 390 × 844 in the dark scheme. The default state rendered one
route, 300 tasks, and the Anthropic readout; a `chatgpt-plus` selection serialized
`plan`, `models`, and `tasks`, restored those values on reload, and updated the
readout before paint. The 1440px document measured `scrollWidth ===
clientWidth === 1440`; the 390px document measured `scrollWidth ===
clientWidth === 390`, with a 342px listing table inside a 390px viewport. The
built page emitted no `.json` or `/api` requests during reload and interaction.

`bun run build` completed 53 pages and generated the 1200 × 630 social card.
`bun run check` completed with zero errors after the final source pass; the
focused `bun test apps/site/src/lib/readout.test.ts` run completed with 2
passes and 0 failures. The impeccable detector reported no output for
`apps/site/src/pages/index.astro`. The deferred consumers remain UI-507 through
UI-513; this route does not change data, packages, URL meaning, or arithmetic.
